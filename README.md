COMO USAR O UNPACK:

    python digi.py -unpack <caminho-do-arquivo> <caminho-da-tbl> <caminho-da-tbl-2chars>

Exemplo:

    python digi.py -unpack MESPAK00.PAK xros.tbl xros_2chars.tbl

COMO USAR O REPACK:

    python digi.py -repack <caminho-da-pasta> <caminho-da-tbl> <caminho-da-tbl-2chars>

Exemplo:

    python digi.py -repack CAMINHODAPASTA/NOMEDOARQUIVO xros.tbl xros_2chars.tbl
